# Daily Project

## Banking System

Beginning on **Day 04**, a banking system was developed and enhanced throughout the module to practice object-oriented programming and software engineering concepts.

### Features

- Account creation
- Savings Account
- Current Account
- Deposit & Withdraw
- Interest calculation
- Overdraft support
- Account statements
- Account Factory
- Account Registry
- SMS Alert Service
- Observer Pattern
- Transaction History
- Undo Last Transaction
- Search Accounts
- Sort Accounts by Balance
- Binary Search
- Tree Traversal
- Graph Traversal
