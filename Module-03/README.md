# Module 03 – React & Next.js

## Overview

This module contains solutions to the daily exercises and projects from **Module 03** of the Full Stack Software Development course provided by **IBT College**.

This module focuses on modern frontend development using **React** and **Next.js**. It covers building interactive, component-based user interfaces, managing application state, handling forms and events, working with APIs, and developing full-stack web applications.

# Projects

## React Capstone Project - Mesob House

### Features

- Explore Today's Specials.
- Browse the full menu by category.
- Search dishes by English or Amharic name.
- View individual dish details.
- Add dishes to a shared shopping cart.
- Update quantities and remove cart items.
- Create a local account.
- Sign in with the local account.
- Continue browsing as a guest.
- Proceed through a protected checkout flow.
- Submit delivery and payment selections through client-side validation.
- Receive a checkout confirmation.
- Navigate through responsive mobile and desktop layouts.
- Receive a dedicated 404 page for unknown routes.
- Recover from rendering errors through a React Error Boundary.

## Next.js Capstone Project - Mesob House

### Features

#### Customer Features

- Browse Ethiopian dishes.
- Search dishes by English and Amharic names.
- Filter dishes by category.
- View individual dish details.
- Add dishes to a persistent shopping cart.
- Update quantities and remove cart items.
- Submit orders after signing in.
- View personal order history.
- Track order status with periodic updates.
- View demonstration delivery locations on a map.

#### Staff Features

- Access a staff-only kitchen page.
- View all orders in the kitchen.
- View dashboard order statistics.
- Visualize revenue by neighbourhood.
- Sort and paginate order records.

# Skills Practiced

## React

- React fundamentals: Components, Props, State, and JSX.
- React Hooks and managing component state.
- Routing and navigation.
- Context API and global state management.
- Forms and controlled components.
- Form validation using Zod.
- Error Boundaries and error handling.
- Event handling and user interactions.
- Keyboard, mouse, and touch accessibility.

## Next.js

- Next.js fundamentals and App Router.
- Server Components and Client Components.
- Layouts, nested routes, and dynamic routes.
- Data fetching and API integration.
- Route Handlers and Server Actions.
- Forms and form submissions using `useActionState`.
- Caching, revalidation, and data synchronization.
- Authentication and authorization.
- Cookies, sessions, and protected routes.
- State management using Zustand.
- Search, filtering, and debouncing.
- Dashboards, charts, tables, sorting, and pagination.
- Loading states, error handling, and error boundaries.
- Maps and geographical data using Leaflet.
- Real-time data concepts: Polling, Server-Sent Events (SSE), and WebSockets.
- Internationalization and formatting using the JavaScript `Intl` API.
- Working with JSON, CSV, and browser file APIs.
- Production builds and deployment concepts.
