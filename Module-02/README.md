This module contains solutions to the daily exercises and projects from **Module 02** of the Full Stack Software Development course provided by **IBT College**.

The module focuses on frontend web development using **HTML, CSS, and JavaScript**, with an emphasis on building interactive and responsive web applications using vanilla JavaScript and browser APIs.

# Projects

## Addis Market Shopping List

An interactive shopping list application built with vanilla JavaScript.

### Features

- Add shopping items
- Enter item names and ETB prices
- Validate form input
- Dynamically render items using DOM methods
- Mark items as bought
- Delete items using event delegation
- Display a live running total of ETB prices

## Country Facts Page

A single-page application that allows the user to search for a country and display information retrieved from an external API.

### Features

- Search for a country
- Fetch country data from an API
- Display the country name
- Display the capital
- Display population
- Display region
- Display the country flag
- Show a loading state
- Handle errors
- Dynamically create and render DOM elements

## Birr Watch

A responsive, data-driven web application designed to track real-time Ethiopian Birr (ETB) exchange rates, convert currencies, and persist a personalized watchlist across browser sessions.

### Features

- Live Exchange Rates
- Real-Time Currency Conversion
- Dynamic Watchlist
- Local Persistence.
- Error & Loading UI
- Mobile-First Responsive UI
- Light/Dark Theme

## Addis Eats

A responsive, single-page food ordering app built with vanilla JavaScript and Tailwind CSS. **Addis Eats** allows users to browse traditional and modern Ethiopian dishes, filter by category, search live, manage a persistent shopping cart in ETB, and place orders through a validated TeleBirr checkout form.

### Features

- Dynamic Menu Rendering
- Live Search & Category Filter
- TeleBirr Checkout Form
- State-Driven UI Architecture
- Mobile-First Responsive UI
